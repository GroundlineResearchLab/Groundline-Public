# Groundline-Public Indexes

**Project:** Groundline Research Lab

**Repository:** Groundline-Public

**Section:** Public Indexes

**Framework:** DGCP™

## Purpose

The `indexes/` directory provides structured navigation across public Groundline Research Lab outputs.

Indexes are intended to help readers locate, verify, and connect published material without changing the meaning or evidentiary status of the underlying records.

An index is a navigation layer.

It is not a substitute for the original publication.

## Scope

Indexes may be created for:

• Articles.
• Briefs.
• Explainers.
• Public research records.
• Datasets.
• Methodology notes.
• Evidence records.
• Research themes.
• Data domains.
• Publication dates.
• Source categories.

Additional index types may be introduced as the public repository expands.

## Index Principles

Public indexes should preserve:

1. Accurate record titles.
2. Canonical repository paths.
3. Record identifiers where available.
4. Publication dates.
5. Publication type.
6. Relevant subject or domain.
7. Current record status where necessary.

Indexes should not silently redefine or reinterpret the publication they reference.

## Canonical Record

The indexed file remains the canonical source for its substantive content.

An index entry should provide navigation and metadata only.

If an index and the original record differ, the original canonical record takes precedence unless an official correction states otherwise.

## Record Status

Where useful, index entries may identify status such as:

• Active.
• Updated.
• Corrected.
• Superseded.
• Archived.

Status labels should reflect documented repository history.

They should not be inferred without evidence.

## Index Structure

Future index files may be organized by year, month, topic, publication type, or research domain.

Example:

```text
indexes/
├── README.md
├── 2026/
│   └── 09/
├── topics/
└── publication-types/
```

Directories should be introduced only when actual public records require them.

## Traceability

Index entries should point to the public record being indexed.

Where a publication has been corrected, updated, or superseded, the index may also record the relationship between versions.

Historical traceability should be preserved where materially relevant.

## Public Boundary

Indexes must reference only material approved for public release.

Internal research records, private working files, restricted sources, or unpublished research should not be exposed through the public index.
