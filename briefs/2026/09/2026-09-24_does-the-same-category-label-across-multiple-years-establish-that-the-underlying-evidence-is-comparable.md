# Does the Same Category Label Across Multiple Years Establish That the Underlying Evidence Is Comparable?

**Date:** 24 September 2026

**Domain:** Classification Definitions and Temporal Comparability

**Publication Type:** Brief

## Question

Does repeated use of the same category label across multiple years establish that the evidence grouped under that category remains comparable?

## What the Evidence Shows

No.

A category can retain the same visible name while the rules determining what enters that category change.

The central distinction is:

**Same Label ≠ Same Definition**

Category-based evidence depends not only on the label attached to a group but also on the definition and classification system used to assign observations to it.

Relevant elements can include:

| Element                | What It Determines                                 |
| ---------------------- | -------------------------------------------------- |
| Category label         | The visible name assigned to the group             |
| Operational definition | What the category represents                       |
| Inclusion criteria     | Which observations qualify                         |
| Exclusion criteria     | Which observations do not qualify                  |
| Classification rules   | How observations are assigned                      |
| Thresholds             | Conditions separating categories                   |
| Coding procedures      | How source information becomes a category code     |
| Reference population   | Which observations are eligible for classification |

If these elements change, observations carrying the same category name in different periods may not represent the same underlying group.

Eurostat treats comparability over time as a specific statistical quality issue. Its quality and metadata guidance distinguishes between situations in which no relevant changes have occurred, situations in which changes exist but are not sufficient to create a break in series, and situations in which changes are substantial enough to create such a break.[1]

The persistence of a category label therefore does not independently establish continuity of the underlying evidence.

## The Label Can Stay While the Classification Changes

The Office for National Statistics provides a clear example in its Census 2021 documentation for the economic category variable.

ONS describes the variable as **broadly comparable** with the 2011 Census rather than identical. It notes that wording changed in the Census 2021 questionnaire and that some response options were removed.[2]

ONS also explains that a variable classified as broadly comparable can still involve changes to the question, available response options, or the way written answers are classified.[2]

The subject remains economic category.

But the comparability of the resulting evidence depends on more than continuity of the variable name.

A stronger example appears when an entire classification system is revised.

When the UK Standard Occupational Classification moved from SOC 90 to SOC 2000, ONS used correspondence matrices derived from dual-coded Labour Force Survey data to estimate how historical observations classified under SOC 90 would have been classified under SOC 2000.[3]

The historical evidence could therefore not simply be treated as though the classification system had remained unchanged.

## What Can Change Beneath a Stable Category Label

A category may retain the same name while one or more of the following changes:

* Its formal definition.
* Inclusion or exclusion criteria.
* Classification thresholds.
* Coding instructions.
* Questionnaire wording.
* Available response categories.
* Automated classification procedures.
* The population eligible to enter the category.
* The surrounding category structure.

Changes to neighboring categories can also alter the composition of a category that appears unchanged.

For example, if one category is divided into several new categories, observations that previously belonged to another group may be reassigned even if that group's own label survives.

This means that visual continuity in a table does not necessarily establish conceptual continuity in the evidence.

## Correspondence Across Classification Versions Matters

Classification revisions do not necessarily make historical comparison impossible.

Statistical systems can create mappings between old and new classifications.

Eurostat describes correspondence tables as important tools for comparing statistical data collected and presented using different classifications. Tables connecting different versions of the same classification document the detailed changes introduced during revision.[4]

Such mappings can show how categories correspond across versions.

But the need for correspondence information illustrates the underlying point:

**Comparability comes from evidence about the relationship between classification systems, not from the persistence of a category label alone.**

ONS's SOC backcasting work demonstrates the same principle in practice. Historical observations were transformed using empirically derived relationships between SOC 90 and SOC 2000 categories rather than assumed to be directly interchangeable.[3]

## The Composition of a Category Can Change

Consider a category called:

`Category A`

In an earlier period, its definition might be:

`Observations meeting conditions X and Y`

Several years later, the category may still be called:

`Category A`

but the definition may now include:

`Observations meeting X, Y, or newly added condition Z`

The label did not change.

The membership rule did.

An increase in the number of observations assigned to Category A could therefore reflect:

`Change in the Underlying Phenomenon`

or:

`Change in the Classification Definition`

or some combination of both.

Without information about the classification change, the numerical difference cannot automatically be attributed entirely to a change in the real-world condition being measured.

## What the Same Category Label Does Not Establish

Repeated use of the same category name does not by itself establish that:

* The operational definition remained unchanged.
* The same inclusion criteria were applied.
* The same exclusion criteria were applied.
* Classification thresholds remained constant.
* Coding procedures remained unchanged.
* The same population was eligible for classification.
* Neighboring categories retained the same structure.
* An observation would have received the same classification under earlier rules.
* The category has the same composition across periods.
* A change in category counts represents only real-world change.
* Values from different years form one directly comparable continuous series.

The reverse also matters.

A classification change does not automatically make all historical comparison impossible.

Statistical producers may use correspondence tables, dual coding, backcasting, recalculation, or revised historical series to improve comparability.

Those procedures can provide additional evidence supporting historical comparison.

The category label itself cannot.

## Why It Matters

Category-based data often look stable because the same words appear repeatedly in historical tables, dashboards, reports, and datasets.

That visual continuity can conceal definitional change.

A category may retain its name while its membership changes.

A classification may retain familiar high-level groups while the observations assigned within those groups change.

A time series can therefore appear continuous even when the underlying classification system has been revised.

The narrower principle is:

**A stable category label establishes continuity of naming. It does not independently establish continuity of meaning.**

When category definitions or classification systems change, the interpretation of historical differences depends on how those changes affected the evidence represented by each category.

## Limits

This brief addresses one narrow evidence problem: whether a stable category label establishes comparability of the underlying evidence across time.

It does not establish that every definitional or classification change creates a material break in a statistical series.

Some revisions may have little practical effect.

Some categories may remain sufficiently comparable despite documented changes.

ONS, for example, uses the description **broadly comparable** where changes exist but general comparison remains possible.[2]

The public sources reviewed for this brief do not establish:

* A universal threshold at which definitional change destroys comparability.
* That every wording change alters category membership.
* That every classification revision reduces data quality.
* That newer definitions are inferior to earlier definitions.
* That historical data cannot be reconciled after classification changes.
* That correspondence tables eliminate every comparability limitation.
* That identical category definitions guarantee complete comparability when other parts of the measurement system change.

The effect of a classification change depends on the nature of the revision and the comparison being attempted.

The specific issue here is narrower than general measurement consistency.

It is whether an apparently stable category continued to represent sufficiently comparable evidence across the periods being compared.
